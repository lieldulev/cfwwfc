Square terrain

Full generateMap on a square grid with weighted, isotropic terrain tiles. Adjacency is symmetric: each tile only allows neighbors it agrees with (e.g. water meets water or sand). Tooltip shows id and rotation (isotropic tiles look the same at any 90° step).

Run npm run build, then serve the repo root (e.g. npx serve .) and open /examples/square-terrain/ — ES modules need HTTP, not file://.
