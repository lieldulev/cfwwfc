Square terrain — roads & rivers on grass / sand

Like square-terrain, with socketed grass/sand variants: each side is open, road, or river, and neighbors must match on the shared edge. Straights, caps, corners, and road×river crossings are a single tile id each; tileAllowed receives self and neighbor (with rotations) plus both local edge indices so rules stay correct under rotation.

Run npm run build, then serve the repo root and open /examples/square-terrain-roads-rivers/.
